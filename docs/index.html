추정분할계산기

2026학년도 고교학점제 성취평가제 · 추정분할점수 산출 보조 도구

산출 원리: 난이도 범주별 배점합 × 성취수준별 최소 능력자 예상 정답률 합산
문항을 쉬움·보통·어려움 3개 난이도로 분류하고, 각 난이도 범주에서 성취수준별 최소 능력자가 맞힐 것으로 예상되는 정답률(%)을 입력합니다. 동일 난이도 범주가 하나의 성취수준 목표 문항으로만 구성되면 약 65%를 기준으로 추정합니다. 예상 정답률은 A~D는 5% 단위, E는 1% 단위로 입력합니다.
평가단계:
예상정답률 구분:
문항구분 난이도 해당문항번호 문항수 배점합 최소능력자 예상정답률(%)

배점합과 예상 정답률을 입력하면 자동 계산됩니다
주의: 본 계산기는 교과협의 및 나이스 입력 전 검토를 돕는 보조 도구입니다. 실제 분할점수는 교과 협의를 통해 결정하고 나이스에 입력해야 합니다. 분할점수를 의도적으로 높이거나 낮춰 특정 성적 분포를 만드는 것은 금지됩니다.
사용방법 — 정기시험 추정분할점수 입력 가이드 ▼
📌 STEP 1. 문항을 난이도로 분류하기
출제된 문항 전체를 쉬움 / 보통 / 어려움 3가지 난이도로 분류합니다.
분류 기준은 교과 협의에서 정하며, 일반적으로 아래 기준을 참고합니다.
🟢 쉬움
기초 개념 확인 문항
대부분 학생이 맞힐 수 있는 문항
🟡 보통
핵심 개념 적용 문항
중간 수준 학생이 맞힐 수 있는 문항
🔴 어려움
심화·응용 문항
상위 수준 학생 대상 변별 문항
📌 STEP 2. 선택형·논술형 배점합 입력
각 난이도별로 선택형(객관식) 배점 합계와 논술형(서술·단답형) 배점 합계를 따로 입력합니다.
예시: 100점 만점 시험
쉬움: 선택형 21점 + 논술형 0점
보통: 선택형 34점 + 논술형 15점
어려움: 선택형 16점 + 논술형 14점
→ 합계: 선택형 71점 + 논술형 29점 = 100점
📌 STEP 3. 성취수준별 예상 정답률(%) 입력
각 성취수준(A~E)의 최소 능력자(MCP)가 해당 난이도 문항을 맞힐 것으로 예상되는 정답률을 입력합니다.
입력 규칙:
• A~D 성취수준: 5% 단위로 입력 (예: 90, 85, 80…)
• E 성취수준: 1% 단위로 입력 (예: 55, 48, 32…)
• 반드시 A > B > C > D > E 순서 유지
• 쉬운 문항일수록 정답률이 높게, 어려운 문항일수록 낮게 설정
참고 예시 (쉬움 문항):
A: 90% B: 80% C: 70% D: 60% E: 55%
어려움 문항 예시: A: 75% B: 55% C: 40% D: 25% E: 15%
📌 STEP 4. 결과 확인 및 나이스 입력
입력값을 넣으면 A~E 분할점수와 점수 영역이 자동 계산됩니다.
결과를 교과 협의에서 검토 후 나이스에 입력합니다.
나이스 입력 경로:
교과담임 → 성적처리 → 분할점수 → 정기시험추정분할점수산출관리
산출 원리: 평가요소별 성취수준 최소 능력자 배점 합산 → 점수 영역 설정
채점기준표의 각 평가요소에서 성취수준별 최소 능력자에게 부여되는 배점을 입력합니다. 각 성취수준의 배점 합계가 해당 성취수준의 분할점수(최소 점수)가 됩니다. 점수 영역은 해당 성취수준 최소점수 ~ 바로 위 성취수준 최소점수 -1 로 자동 설정됩니다.
평가요소별 성취수준 최소 능력자 배점 입력
평가요소 A 배점 B 배점 C 배점 D 배점 E 배점 만점
배점을 입력하면 자동 계산됩니다
사용방법 — 수행평가 추정분할점수 입력 가이드 ▼
📌 STEP 1. 채점기준표에서 평가요소 확인
수행평가 채점기준표를 펼치고 평가요소를 확인합니다.
평가요소는 대개 2~5개로 구성되며, 각 요소마다 성취수준별 배점이 정해져 있습니다.
예시: 코딩 수행평가 채점기준표
평가요소 1: 코드 정확성 (A:4점 / B:3점 / C:2점 / D:1점 / E:1점, 만점 4)
평가요소 2: 문제 해결 능력 (A:4점 / B:2점 / C:2점 / D:1점 / E:1점, 만점 4)
평가요소 3: 설명 능력 (A:2점 / B:1점 / C:1점 / D:1점 / E:1점, 만점 2)
📌 STEP 2. MCP(최소 능력자) 배점 입력
각 평가요소에서 해당 성취수준에 가시소로 도달한 학생(MCP)에게 부여되는 배점을 입력합니다.
표에서 A 배점 > B 배점 > C 배점 > D 배점 > E 배점 순서를 유지해야 합니다.
주의사항:
• 만점은 해당 평가요소의 실제 만점 점수를 입력
• A 배점은 만점과 같거나 만점에 가까운 값으로 설정
• E 배점은 가장 낙은 점수 (0점도 가능)
📌 STEP 3. 결과 확인 — 자동 계산
배점을 입력하면 성취수준별 분할점수 = 각 평가요소 MCP 배점의 합계가 자동 계산됩니다.
나이스 입력 경로:
교과담임 → 성적처리 → 분할점수 → 수행평가추정분할점수산출관리
학기말 추정분할점수산출 결과
나이스 학기말 추정분할점수산출 화면과 동일한 결과표 형식입니다. 정기시험 + 수행평가 반영비율을 입력하면 성취수준별 추정분할점수와 평균점수가 자동 산출됩니다.
📋 정기시험/수행평가 목록 입력
구분 고사/영역 명 반영비율(%) 배점 A/B B/C C/D D/E 삭제
[반영비율] 및 [분할점수]를 입력하면 나이스 학기말 추정분할점수산출 결과표가 자동 생성됩니다
⚠️ 나이스 입력 경로: 교과담임 → 성적처리 → 분할점수 → 학기말 추정분할점수산출
📖 이렇게 입력하면 돼요! (클릭하면 접혀요) ▼
🗺️ 전체 흐름 한눈에 보기

① 정기시험 탭에서 A/B, B/C, C/D, D/E 분할점수를 먼저 구하고,
② 수행평가 탭에서 각 수행평가의 분할점수를 구한 다음,

📌 반영비율(%)
이 평가가 최종 성적에서 몇 %를 차지하는지 적는 칸이에요.
예: 정기시험 50% + 수행평가A 25% + 수행평가B 25% = 합계 100%
⚠️ 모든 줄의 반영비율을 더하면 반드시 100이 되어야 해요!
📌 배점
이 평가의 만점이에요. 보통 100점이에요.
예: 100
📌 A/B, B/C, C/D, D/E (파란/초록/주황/보라 칸)
이게 핵심이에요! 앞에서 계산한 추정분할점수를 여기에 옮겨 적어요.
A/B = A와 B의 경계점수 (이 점수 이상이면 A)
B/C = B와 C의 경계점수 (이 점수 이상이면 B)
C/D = C와 D의 경계점수 (이 점수 이상이면 C)
D/E = D와 E의 경계점수 (이 점수 이상이면 D)

추정분할점수란?

추정분할점수는 성취도(A~E)를 나누는 기준점수를 단순히 90/80/70/60/40점으로 고정하지 않고, 실제 평가 문항의 난이도·구성과 각 성취수준 최소 능력자(MCP)의 수행 특성을 반영하여 적절한 분할점수를 추정하는 방식입니다.
